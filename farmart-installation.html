What is Farmart?

Farmart is a Laravel ecommerce system built on Botble CMS. It can run as a straightforward single-seller store or as a multivendor marketplace where vendors get their own dashboard, products and payouts.

The storefront leans grocery and organic by design, but the catalogue model is flexible: electronics, furniture, fashion and general merchandise all work. Because it sits on Botble, you also inherit a real CMS — pages, blog, menus, sliders and SEO controls.

It is one of the more reasonably priced Laravel shops at this feature level, which makes it a popular choice for regional stores that need local payment gateways and RTL support rather than another WooCommerce site.

Server requirements and what to prepare

✓ PHP 8.3 or higher with PDO, OpenSSL, Mbstring, Exif, Fileinfo, XML, Ctype, JSON, Tokenizer and cURL
✓ MySQL database with a dedicated user
✓ Apache or Nginx with mod_rewrite and HTTPS
✓ cPanel or DirectAdmin style hosting plus Composer (VPS works too, with the panel or CLI)
✓ SMTP credentials for order email
✓ Payment gateway merchant accounts for the gateways you enable

Single-vendor or multivendor — which should I choose? +
If you only sell your own stock, single-vendor is simpler. Choose multivendor when other sellers will list products and you take a commission. It can be configured either way.
Which gateways are included? +
PayPal, Stripe, Paystack, Razorpay, Mollie and SSLCommerz are built in, with more available as paid add-ons. Tell me which you need and I will confirm.
Can I use my own theme design? +
Yes, within Botble's theme system. I can apply branding, colours and layout changes without breaking upgrades.
Does it include a mobile app? +
No. The package is the web store. A separate app is sold by the same author, and I can help connect it once you have a licence.
