What is Pickbazar?

Pickbazar is a modern ecommerce stack rather than a single application: a Laravel backend exposing both REST and GraphQL APIs, plus two separate Next.js frontends — the customer shop and the admin dashboard — written in TypeScript and Tailwind.

That architecture has real advantages. The shop is fast and SEO-friendly because it is server-rendered, and you can later add a mobile app that consumes the same API. It also means three deployments to maintain, which is why the listing itself warns against cheap cPanel hosting.

It is one of the most feature-complete multivendor shops at this price, with vendor staff roles, withdrawals, refund policies, wallet points and more than a dozen payment gateways. Budget for a VPS and for the setup work that the architecture demands.

How a Pickbazar setup works

01
Environment planning
VPS or cloud instance with Node 22+, PHP 8.x, MySQL, Composer and npm, plus SSH access. I plan the subdomains or domains for the API, shop and admin before deploying.
02
Backend deploy
Install the Laravel API, create the database, run migrations and seeders, and configure the environment file with your domains and keys.
03
Frontend builds
Install and build the Next.js shop and admin apps, then point them at the API. This is where Node versions and API URLs cause most failed installs, so I pin them deliberately.
04
Domains, SSL and proxies
Map domains or subdomains to each app, set HTTPS everywhere and use a reverse proxy so the three services coexist cleanly.
05
Store configuration
Gateways, currency, shipping, taxes, vendors, commissions, emails and Pusher for live notifications.
06
Performance and handover
Caching, image optimisation and a full order test on the live domain before handover.
