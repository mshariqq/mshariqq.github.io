What is Active eCommerce CMS?

Active eCommerce CMS is a Laravel multivendor ecommerce platform with a customer storefront, a seller panel and a full admin panel. It supports business-to-customer, business-to-business and customer-to-customer selling, physical, digital and classified products, and a long list of optional modules.

The core is capable but modular by design: OTP, POS, auction, refunds, wholesale pricing, seller subscriptions and courier integrations are separate paid add-ons. Mobile apps are also separate items. Budget accordingly instead of assuming everything on the sales page is included.

Installation is a web installer, but the details matter: the document root, permissions on public/uploads and public/all, the purchase-key domain activation and add-on version compatibility. Those are the areas I handle and test so the store is stable before you add products.

How a Active eCommerce CMS setup works

01
Server and PHP
I confirm PHP 8.x, MySQL 8.x, the required extensions, mod_rewrite and HTTPS, then set the document root correctly. A wrong root or missing extension is the usual cause of a 500 on first load.
02
Files, database and installer
Extract the install package into the web root, create the database and run the web installer. I set APP_URL and the environment values, then verify the admin login works.
03
Permissions and storage
Set 755 on public/uploads and public/all for local storage, or configure S3-compatible storage. I test an actual product image upload rather than assuming permissions are right.
04
Activation and add-ons
Activate the licence for the correct domain, then install only the add-ons you own. Add-on versions must match the core, and mismatches are a common source of broken admin pages.
05
Payments, shipping and seller rules
Configure gateways, shipping methods, commissions, seller approval and payout rules, then place a test order as a customer and fulfil it as a seller.
06
Migration and handover
If you are moving from another platform, I map products, customers and orders rather than promising a magic one-click import. Then I hand over with a short admin walkthrough.
