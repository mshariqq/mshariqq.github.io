What is WoWonder?

WoWonder is a self-hosted PHP social network platform: a news feed with friends and follows, pages, groups, events, a messenger, blogs, marketplace listings and pro memberships. It is the kind of script people choose when they want a Facebook-style community they own instead of a hosted community tool.

It is plain PHP and MySQL rather than Laravel, and the package ships as source you upload to your own server. The author also sells native Android and iOS apps that talk to the same API, but those apps are separate purchases and are not part of the script licence.

The big caveat is maintenance. A social site is media-heavy, mail-heavy and cron-dependent, and this item was last updated in May 2024. A clean install on a current PHP 8.x stack is straightforward, but I check extension and PHP compatibility before promising anything on your host.

How a WoWonder setup works

01
Hosting and PHP
I confirm PHP 8.x with MySQLi, GD, mbstring, cURL and allow_url_fopen, then set upload and memory limits that match a media-heavy site. Most failed installs are actually a host with tight limits.
02
Files and database
Upload the script, create the MySQL database and import the SQL, then run the installer and write the site URL, database and mail settings. Permissions are set so uploads work without making the whole site writable.
03
Cron and mail
Social scripts fall apart without scheduled jobs. I add the cron entries for feeds, notifications and clean-up, then configure SMTP so signup and reset emails actually arrive instead of landing in spam.
04
Media and limits
Set image and video limits, thumbnail sizes and storage rules. If you expect heavy media, I move uploads to object storage or a CDN instead of letting the server fill up.
05
Moderation and pages
Configure categories, pages, groups, reporting, bad-word filters and admin roles, then create the first few pages so the site does not look empty on launch.
06
Apps and handover
If you own the native apps, I point them at your API, set push keys and produce test builds. Either way I walk through registration, posting and messaging on a real phone before handover.

Server requirements and what to prepare

✓ PHP 8.0-8.2 with MySQLi, GD, mbstring and cURL, plus allow_url_fopen enabled
✓ MySQL 5.7+ or MariaDB 10.3+ with a dedicated database and user
✓ Apache or Nginx with mod_rewrite, HTTPS and a document root you control
✓ Cron access for scheduled feed, notification and cleanup jobs
✓ SMTP credentials or a transactional mail service with SPF and DKIM
✓ Enough disk for user media, plus a CDN or object storage for scale

Videos stuck processing? +
FFmpeg missing or cron off. I install FFmpeg on VPS, set paths, limits and background jobs.

Is WoWonder built on Laravel? +
No. It is a standalone PHP and MySQL script. That matters for hosting and for any developer you hire, because Laravel skills do not automatically transfer to its codebase.
Are the mobile apps included? +
No. The Android and iOS apps are sold as separate items. I can install the web script, then configure and build the apps if you own those licences.
Why do uploads or emails fail after install? +
Usually PHP upload limits, missing GD or mbstring, wrong file permissions, or no SMTP and cron. I check all four during setup instead of leaving you to debug them later.
Can you upgrade an older WoWonder site? +
Yes, after a backup and a review of your theme and custom changes. The item has not been updated since May 2024, so I test PHP compatibility on a staging copy first.
Will it handle a large community? +
Not on cheap shared hosting. Media, chat and notifications need CPU, disk and bandwidth, so I size the server for your expected traffic and add a CDN for images and video.
