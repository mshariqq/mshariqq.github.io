What is eBroker?

eBroker is a real estate marketplace package: Flutter apps for buyers and agents, a Next.js property website and a Laravel admin panel. Listings cover sale and rent, with map search, filters, featured packages, agent profiles, chat and Firebase push notifications.

This is three codebases, not one. The Laravel panel drives the API and data, the Next.js site serves SEO-friendly property pages, and the Flutter apps are built separately for Android and iOS. Each part has its own build and deployment steps.

That structure is powerful but demanding. Maps and Places billing, Firebase configuration, app signing and three deployments are all part of going live. I plan them together so the app, web and admin show the same listings and pricing.

How a eBroker setup works

01
Server and Laravel admin
I set PHP 8.x, MySQL, Composer and a public document root, then install the admin panel, import the database and configure the API URL and storage.
02
Web front end
Deploy the Next.js site with the correct API endpoint, build it for production and connect the domain. SEO settings and sitemap generation are checked here.
03
Maps, Firebase and mail
Set Maps and Places keys with billing, Firebase for push and auth where used, and SMTP for transactional mail. Then I verify that a new listing appears on the map and on the website.
04
Packages, roles and moderation
Configure listing packages, featured promotions, agent approval and reporting rules so the marketplace is monetised and moderated from day one.
05
Flutter apps
Set the API base URL, Firebase files and Maps keys, rename the package, then produce signed Android and iOS builds. I test chat and push between two real devices.
06
End-to-end test
I post a property from the app, approve it in admin, check it on the Next.js site and confirm the enquiry reaches the agent. That complete loop is the real acceptance test.

Is the website included or only the apps? +
Both. The package includes Flutter apps, a Next.js website and a Laravel admin panel. That is why installation is more involved than a single script.
Do I need a VPS? +
For the full stack with SEO enabled, yes. Shared hosting may work only with advanced SEO disabled. I confirm the target host before quoting.
Why are maps not loading? +
Missing or unrestricted API keys, billing not enabled, or a key restricted to the wrong domain or package. I configure and test the keys during setup.
How long does the full install take? +
The admin API is usually a day. The Next.js site and two signed apps with Firebase and Maps normally take several days depending on store accounts.
Can you customise the app design? +
Yes. Flutter theming is separate work from the Laravel or Next.js changes, so I scope it per screen rather than promising a single flat price.
