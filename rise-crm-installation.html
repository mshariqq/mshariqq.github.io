What is RISE CRM?

RISE CRM is a CodeIgniter 4 application for running a service business: clients and leads, projects and tasks, estimates and proposals, invoices and subscriptions, support tickets, contracts, a client portal and team chat. It is closer to an agency operating system than a simple contact database.

It is not Laravel and not a SaaS platform by default. One install serves one company, with roles for staff and separate client logins. The author sells a SaaS plugin separately if you want to host multiple tenants, and official plugins add modules that are not in the core.

Most installation pain is not the code upload. It is mail: recurring invoices, email-to-ticket and password resets all depend on cron, SMTP and often IMAP. Those are the parts I set up and test rather than leaving as an exercise for you.

How a RISE CRM setup works

01
Hosting and PHP
I confirm PHP 8.x, MySQL 8.x, the required extensions and a public document root. RISE is PHP-only, so no Node build is needed, but missing intl or mbstring breaks it.
02
Files, database and installer
Upload the package, create the database and run the install wizard. I then set the base URL, file permissions and the upload paths used for contracts and ticket attachments.
03
Mail and ticket piping
Configure SMTP for outgoing mail and IMAP if you want email-to-ticket. I test a real invoice email and a real inbound ticket, because this is where most RISE installs silently fail.
04
Cron and recurring work
Add the scheduled job that generates recurring invoices, recurring expenses and tasks. Without it, subscriptions look configured but never bill.
05
Roles, taxes and gateways
Set company details, tax rules, invoice numbering, staff roles and the payment gateways you use, then run a test invoice through payment and reconciliation.
06
Client portal and handover
Create a test client, share a file and a project, and confirm the portal works on mobile. Then I walk your team through the daily workflow so the CRM is actually used.

Server requirements and what to prepare

✓ PHP 8.x with intl, mbstring, openssl, PDO, curl, gd, zip and fileinfo
✓ MySQL 8.x with a dedicated database and user
✓ Apache or Nginx with HTTPS and a public document root
✓ Cron access for recurring invoices, tasks and scheduled mail
✓ SMTP for outgoing mail; IMAP extension if you use email-to-ticket
✓ Pusher, Slack, Google Calendar or GitHub accounts only if you enable those integrations

FAQ

Installer stuck / 500 error? +
PHP version or mod_rewrite/permissions. I fix version, .htaccess and folder rights.

Is RISE CRM built on Laravel? +
No. It is CodeIgniter 4. That is good for lightweight hosting, but do not hand it to a Laravel-only developer without checking their comfort with CodeIgniter.
Why are recurring invoices not being generated? +
The scheduled job is missing or failing. RISE needs cron for recurring invoices, expenses and tasks, and I configure and verify it during setup.
Can my clients log in? +
Yes, through the client portal. I create a test client and confirm project, invoice and file access before handover.
Is RISE CRM SaaS-ready? +
Not by default. One install serves one company. The author sells a separate SaaS plugin for multi-tenancy, which is a different project with its own requirements.
Do I need to buy plugins? +
Only for the modules you need. The core covers projects, invoices, tickets, leads and the portal; official plugins add extras and are priced separately.
