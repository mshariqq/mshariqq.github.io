What is HRM HR and Payroll Tool?

HRM is a self-hosted human resources and payroll application. Employee records, attendance, leave, payroll, recruitment, onboarding, performance, training, assets, contracts and meetings all sit in one admin panel, with an employee self-service area for payslips and leave requests.

It runs on a Laravel backend with a React frontend that must be compiled. That build step is the main technical difference from simpler scripts: you need SSH, Composer and Node on the server, not just a file upload.

Each installation covers one company. If you want to sell HR as a subscription service to many companies, that is a different, multi-tenant Codecanyon product — worth knowing before you buy the wrong licence.
