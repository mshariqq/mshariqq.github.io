What is Chauffeur?

Chauffeur is a WordPress theme for taxi, limo, chauffeur and car-hire businesses. Unlike most themes, the booking engine is built in: customers choose a vehicle, enter pickup and drop-off, see a route and estimated time, and pay online.

Pricing is flexible. You can charge per mile or kilometre, per hour, a flat rate between two points, a minimum charge and a surcharge, with passenger and baggage limits per vehicle. That covers airport transfers, hourly chauffeur hire and fixed-price city runs.

It is a website product, not an app platform. There is no native customer or driver app in the package, and no live driver tracking. If you need apps and dispatch, that is a separate build, and I will tell you that before you buy the theme expecting an Uber clone.

How a Chauffeur setup works

01
WordPress and theme
Install WordPress on a host with PHP 8.x and MySQL, upload the theme and the bundled WPBakery plugin, then activate the licence. A clean install avoids conflicts with page builders.
02
Demo import and branding
Import the demo, set the logo, colours and typography, and replace every demo image with licensed photos of your own fleet. Demo images are placeholders, not production assets.
03
Maps and route pricing
Create a Google Maps API key with billing and the right API restrictions, then test autosuggest and route time. Without billing the map loads grey and bookings cannot calculate distance.
04
Pricing rules
Set distance, hourly, flat-rate, minimum and surcharge rules per vehicle, plus passenger and baggage limits. I test several real journeys so quotes are not wrong at checkout.
05
Payments and email
Connect PayPal and Stripe, configure SMTP so booking confirmations arrive, and test a payment plus a refund in sandbox mode before going live.
06
Booking test and handover
Run a complete booking on a phone, confirm the admin receives it, and show your team how to manage vehicles, drivers and bookings.

FAQ

Demo import timeout? +
Raise max_execution_time + memory, import in parts, then configure maps + booking. Covered in both plans.
Who is SHA REEQ? +
SHA REEQ is M Shariq Ahmed (mshariqq) — Hyderabad, 10+ years.
Is a mobile app included? +
No. Chauffeur is a WordPress theme with a web booking system. Native customer and driver apps with live tracking are a separate project, and I will scope that honestly rather than pretend the theme does it.
Do I need a paid Google Maps key? +
Yes. Autosuggest, routes and distance pricing use Google Maps, and Google requires billing. I set the key restrictions so it is not abused.
Can I add Razorpay or another gateway? +
Not out of the box. The theme supports PayPal and Stripe; other gateways need custom development, which I quote separately.
Will it work with Gutenberg? +
The theme is built around WPBakery, which is bundled. Use WPBakery for page edits rather than expecting full block editor support.
Can customers book without paying? +
Yes, you can take bookings with cash or pay-later depending on how you configure the payment step. I set it to match your business rules.
