What is Stocky POS?

Stocky POS is a Laravel and Vue.js retail system: point of sale, inventory, purchasing, invoicing, accounting, HRM, rentals, a CRM pipeline and a small online store. It runs as a single-page app, installs as a PWA and keeps selling when the internet drops.

It suits real counters rather than only warehouses. The POS has five layouts including a touchscreen mode, supports barcode scanners, camera scanning and digital scales, prints thermal receipts and can take several payment methods in one sale.

The base price is generous, including WooCommerce sync and the online store. Some extras, such as the Claude AI assistant and courier integrations, need your own third-party accounts, and charging end users requires the Extended licence.

How a Stocky POS setup works

01
Server and PHP
I confirm PHP 8.x, MySQL 8.x, Composer and a public document root, then size the server for the number of terminals. Offline POS helps, but the sync endpoint still needs to be reliable.
02
Install and migrate
Upload the code, install dependencies, set the environment file, run migrations and seeders, and create the storage link. Then I create the admin and the first warehouse.
03
Front-end build
Build the Vue assets for production and confirm the SPA loads without console errors. If you plan code changes, I set up a repeatable build rather than editing compiled files.
04
Products and stock
Import products by CSV, set variants, barcodes, cost and selling prices, opening stock per warehouse, tax rules and units. Then I test a stock transfer and a physical count.
05
POS hardware and payments
Connect the receipt printer, scanner and scale, configure cash, card and other payment methods, and print a real receipt. Hardware quirks are best solved on site or over a call.
06
WooCommerce and handover
If you sell online, connect the store, map products and run a two-way sync test. Then I train the counter team on opening and closing the till, refunds and offline recovery.

FAQ

Stock duplicating after sync? +
API mapping + cron overlap. I fix keys, mapping, schedules and clean duplicates.
Who is SHA REEQ? +
SHA REEQ is M Shariq Ahmed (mshariqq) — Hyderabad, 10+ years.
Does offline mode really work? +
Yes, the POS keeps selling offline and syncs when the connection returns. I still test recovery carefully, because how you close the till offline affects reconciliation.
Is WooCommerce sync an add-on? +
No, it is included in the base item. I connect the store and run a two-way sync test for products and stock.
Which PHP version does Stocky need? +
PHP 8.x with MySQL 8.x. I check extensions and Composer before installing, since older PHP versions break the Laravel and Vue build.
Can I use it on shared hosting? +
Small single-counter setups sometimes can. Multiple terminals, offline sync and a large catalogue are better on a VPS, and I will say so before you pay.
Do I need the AI assistant? +
No. It is optional and needs your own Claude API access. The POS, stock, invoicing and accounting modules work without it.
