What is Rocket LMS?

Rocket LMS is a Laravel-based learning management system for selling courses. It supports video, text and live classes, single or multiple instructors, course bundles, quizzes, certificates and subscriptions, with a student-facing catalogue and separate instructor and admin panels.

The core item is deliberately modular. Features such as subscriptions, offline payments, extra gateways, quizzes and certificates live in the separately sold plugin bundle, and the mobile app is a separate Flutter item. A realistic budget therefore includes more than the $55 core price.

It is a good fit for academies and creators who want to own their platform instead of paying a percentage to a hosted course marketplace. The trade-off is that you run the server, the cron jobs and the video storage, and you own the upgrades.

How a Rocket LMS setup works

01
Server and PHP
I check the Laravel requirements, PHP 8.x, MySQL and the required extensions, then set the document root to public and confirm HTTPS. A wrong document root is the most common cause of a blank LMS.
02
Files, database and installer
Upload the code, run Composer, create the database and complete the installer. I then set the app URL, storage symlink and the file permissions the uploader needs.
03
Cron, mail and queues
Course reminders, subscription renewals and notifications depend on scheduled jobs. I configure cron and SMTP, then send a real test to confirm students receive enrolment and reminder mail.
04
Courses, instructors and payments
Set up categories, commission rules, instructor approval and the gateways you actually use, then publish a test course and buy it end to end before launch.
05
Video and storage
Choose between local storage, S3-compatible storage, YouTube or Vimeo. For paid video I recommend private object storage so the files cannot be hot-linked from the page source.
06
Plugins and mobile app
Activate the plugins you own, then configure the Flutter app against your API if you bought it. I check the app requires the latest LMS and plugin versions before building.

Server requirements and what to prepare

✓ PHP 8.x with the standard Laravel extensions, Composer and a public document root
✓ MySQL 5.7+ or 8.x with a dedicated database and user
✓ Cron access for reminders, renewals and scheduled notifications
✓ SMTP or a transactional mail service for enrolment and reset emails
✓ Storage for video, ideally S3-compatible object storage plus a CDN
✓ Flutter SDK, Android Studio and Xcode only if you are building the separate mobile app

Course videos failing? +

Do I need the plugin bundle? +
Not to launch basic courses. Subscriptions, quizzes, certificates and many gateways are in the bundle, so most serious course businesses end up buying it. I install whatever you own and tell you what is missing.
Is the mobile app included? +
No. The Flutter app is a separate item and must match your LMS and plugin versions. I can configure and build it if you own the licence.
Why are students not getting reminder emails? +
Almost always missing cron, blocked mail or a wrong sender domain. I configure cron and SMTP and test a real enrolment email before handover.
Can it run on shared hosting? +
Small sites can, if the host supports Composer, cron and PHP 8.x. Video-heavy academies need a VPS and object storage instead.
Can you upgrade my LMS? +
Yes, with a backup and a staging test. Plugin and app versions must move together, so I map the upgrade path before touching the live site.
