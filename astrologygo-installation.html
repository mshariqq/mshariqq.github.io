What is AstroWay?

AstroWay is an astrology consultation platform: a Laravel backend with admin, plus separate Flutter apps for customers and astrologers. Customers chat or call astrologers, generate kundli reports, read horoscopes, book e-pujas and buy products, with per-minute wallet billing.

Real-time work is outsourced to specialist services. Chat runs on Firebase, calls and live streaming on Agora, Zego or 100ms, push on OneSignal, and astrology calculations usually depend on an external API. Each needs its own account, keys and often its own bill.

This is one of the more integration-heavy scripts on Codecanyon. A working install is not just files and a database; it is signed apps, provider keys, wallet and commission rules, and a KYC flow for astrologers. I set those up together and test a paid session end to end.

How a AstroWay setup works

01
Backend and database
I install the Laravel app, configure PHP 8.x, MySQL and the storage driver, then migrate and seed. For media-heavy stores the author recommends object storage, so I plan that from the start.
02
Admin, wallet and commissions
Set currencies, per-minute rates, commission rules, recharge packs, withdrawal rules and KYC requirements. These numbers drive every consultation, so they are tested before apps go live.
03
Provider keys
Create and connect Firebase for chat, OneSignal for push, Agora, Zego or 100ms for calls, and the astrology API for kundli calculations. I restrict keys by package and domain to avoid billing abuse.
04
Astrologer onboarding
Create test astrologers, complete KYC, set availability and rates, and confirm they appear in the customer app with the right price per minute.
05
Flutter apps
Set the API URL, Firebase files, provider keys and app icons, rename both packages, then produce signed Android and iOS builds. I test chat, an audio call and a video call on real devices.
06
Billing test and handover
Run a paid chat and call from wallet top-up to deduction and astrologer earnings, then check the admin reports. That loop is the difference between a demo and a launchable product.

Is the chat self-hosted? +
No. Real-time chat runs on Firebase, with push through OneSignal. That keeps the server load down but means you need those accounts and their configuration done correctly.
Do calls cost extra? +
Yes. Agora, Zego and 100ms bill for usage, and the astrology API may bill per report. I connect them with restricted keys so costs stay predictable.
Why is my wallet billing wrong? +
Usually a rate, currency or commission mismatch, or a provider callback not arriving. I test a full paid chat and call and reconcile the astrologer earnings before handover.
Can I add my own astrologers? +
Yes. They are created in the admin and onboarded through the astrologer app with KYC, rates and availability.
How long does the full setup take? +
The backend is usually one to two days. Two signed apps with Firebase, call providers, KYC and billing tests normally take several days depending on accounts and store review.
