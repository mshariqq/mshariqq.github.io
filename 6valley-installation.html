What is 6Valley Multivendor eCommerce CMS?

6Valley is a self-hosted multi-vendor marketplace script: a Laravel admin and seller panel plus a storefront, shipped together with Flutter customer and seller apps. You can run it as a single shop or open it up to many vendors, and it handles both physical and digital products.

Because it is source code you own, there are no monthly platform fees — you pay for the licence once and host it yourself. The trade-off is that you are responsible for the server, the cron jobs and the mobile app builds, which is where most buyers need help.

It is one of the most popular marketplace scripts on Codecanyon, with thousands of sales, so the feature set keeps growing and updates arrive often. That is good news for features and bad news for upgrades if your copy has been customised.

How a 6Valley Multivendor eCommerce CMS setup works

01
Server and upload
I set PHP 8.2+, MySQL 5.7+, the required PHP extensions and mod_rewrite, then upload the Laravel backend and run Composer. Getting the extensions and public path right first prevents the blank-screen errors most installs hit.
02
Database and installer
Create the database and run the web installer, then set APP_URL, storage symlink and file permissions. The admin account is created here.
03
Cron and queue workers
From v16.6 cron plus a queue worker are mandatory — without them emails and push notifications silently fail. I configure both and verify a test notification actually arrives.
04
Payments, SMTP and shipping
Connect the gateways you actually use, set SMTP so transactional mail is deliverable, and configure shipping method and commissions.
05
Flutter apps
For the full package I set BASE_URL, Firebase (google-services.json / GoogleService-Info.plist), maps keys, rename the package and produce signed release builds for the stores.
06
Handover and testing
I walk through a real order end to end — customer app to seller panel to delivery status — before handing over, so you know the flow works in production.

Server requirements and what to prepare

✓ PHP 8.2 or higher with BCMath, Ctype, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML, Zip, Fileinfo, GD and Sodium
✓ MySQL 5.7+ with a dedicated database and user
✓ Apache or Nginx with mod_rewrite and HTTPS
✓ Cron job plus a supervised queue worker
✓ SMTP credentials so order emails arrive
✓ Flutter SDK, Android Studio and/or Xcode for app builds (full package)
✓ Firebase project plus Maps API keys for the apps

How long does a 6Valley install take? +
Backend-only installs are usually done within 24 hours. Adding the Flutter apps, Firebase, maps and signed store builds normally takes a few days depending on accounts.
Do I need the deliveryman app? +
No. It is sold separately, and the marketplace runs fine without it — you can manage delivery manually or add it later.
Why are my emails and push notifications not sending? +
Almost always a missing cron job or queue worker. Both are required from v16.6 and I configure and test them during setup.
Can you upgrade my old 6Valley to the latest version? +
Yes, but I check your customisations first, because a large version jump can overwrite template and code changes. I confirm the plan before touching anything.
